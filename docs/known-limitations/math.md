# Math blocks

Formula blocks: typing, pasting, importing and drawing them. Part of [Known limitations](../known-limitations.md). How they work: [Math](../math.md).

- **A formula can't be opened full screen.** Images and diagrams have a zoom button, formulas don't, and neither do formulas in presentation mode, version history previews or AI suggestion previews. A formula wider than the note scrolls sideways.
- **A very long formula can freeze the tab while it is drawn.** KaTeX draws the whole formula in one go, and the limits set for it (see [Math](../math.md#for-self-hosters)) stop runaway macros and huge boxes, not length. A formula counts toward the note size limit like any other text, and that is the only bound on its length. How long it takes depends on what is in the formula, and a long one can leave the editor unresponsive for a while.
- **If KaTeX can't be downloaded, a formula shows its source with a message until the formula changes or the note is opened again.** In the editor the block says the formula couldn't be shown and prints its source; the next time the block is drawn, because you changed the source or opened the note again, the download is tried again. A presentation draws each formula once: a formula that failed stays as its source until that slide is redrawn by an edit or the presentation is opened again.
- **Formulas use KaTeX's part of LaTeX.** A command KaTeX doesn't know is marked in red where it stands while the rest of the formula is drawn, a syntax error shows the whole source in red, and a LaTeX package can't be loaded; [the list of what KaTeX supports](https://katex.org/docs/supported.html) is the reference. `\href`, `\url` and the `\html…` commands are switched off for safety and show their name in red and drop their arguments (an unknown command's arguments are still drawn).
- **Fence and language names are matched exactly, in lower case.** ```` ```Math ```` and ```` ```LaTeX ```` stay plain code blocks: not drawn, and for `LaTeX` not colored either (the language list has `latex`). ```` ```tex ```` isn't a language at all.
- **Typing a fence with an input method or a phone's on-screen keyboard hasn't been checked on a real device.** A fence typed with full-width backticks (`｀｀｀math`) is made of different characters and stays text.
- **Undoing a typed conversion can undo the text typed just before it.** Changes made within about half a second are one undo step, so typing ```` ```math ```` and pressing `Enter` in quick succession is undone together, back to an empty paragraph. While the formula's source is open, `Ctrl+Z` undoes inside that text area; press `Esc` first to undo in the note. Diagrams behave the same way.
- **Rolling back to an earlier version deletes formulas.** An earlier version doesn't know about formula blocks. The first time it writes to a note that has them, it removes them from the note, and any write does it, even one that changes nothing near the formula: for example someone who can edit the note opens it in the web app, or an MCP or API write changes any part of it. Back up before rolling back, and read [Upgrading and rolling back](../self-hosting.md#upgrading-and-rolling-back) for what to do about it.
